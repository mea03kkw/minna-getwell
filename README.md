# minna-getwell 🌷

A simple get-well card for Minna 💛

## Live Page

👉 [**View the Get-Well Card**](https://mea03kkw.github.io/minna-getwell)

## About

This is a lightweight, static HTML get-well card built with zero dependencies. No frameworks, no build tools, just a single HTML file.

### Features

- Pure HTML/CSS — no JavaScript required
- Responsive design — works on mobile, tablet, and desktop
- Warm, soft gradient background with a clean card layout
- Written in Cantonese (zh-HK)
- Safe to share via email, Teams, or any link-sharing platform
